# Tasas CUP

Aplicación Android personal para consultar el precio de las monedas (USD, EUR y otras) frente al peso cubano.

- Banderas por moneda, gráfica de barras y línea del último mes, modo claro y oscuro.
- Actualización deslizando hacia abajo y consulta automática cada 3 horas.
- Paquete: `com.appdce.tasascup` · Versión 1.1.0 · Android 8.0+

## Fuente de datos

API oficial de elTOQUE: https://tasas.eltoque.com/docs/
Los datos pertenecen a elTOQUE. Este proyecto no está afiliado ni respaldado por elTOQUE.

## Uso y privacidad

Proyecto personal sin fines comerciales, no publicado en tiendas. No recopila datos personales; el token y el historial se guardan solo en el teléfono.
