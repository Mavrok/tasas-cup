Tasas CUP

Aplicación Android personal para consultar el precio de las monedas frente al peso cubano.

Qué hace

Muestra la tasa de cambio informal del peso cubano (CUP) para el dólar (USD), el euro (EUR) y otras monedas, con la bandera de cada país, una gráfica de barras y línea con la evolución del último mes y modo claro y oscuro.

  • Actualización manual deslizando la pantalla hacia abajo.
  • Consulta automática en segundo plano cada 3 horas.
  • Historial de 30 días guardado en el propio teléfono.

Fuente de los datos

Las tasas se obtienen de la API oficial de elTOQUE (https://tasas.eltoque.com/v1/trmi) con un token personal. Los datos pertenecen a elTOQUE. Esta aplicación no está afiliada ni respaldada por elTOQUE.

Uso previsto

Proyecto personal sin fines comerciales, para uso propio. No se publica en tiendas de aplicaciones y no muestra publicidad. La consulta a la API se hace directamente desde el teléfono del usuario, con pocas solicitudes por día.

Privacidad

La aplicación no recopila datos personales ni usa servidores propios. El token y el historial de tasas se guardan solo en el teléfono.
